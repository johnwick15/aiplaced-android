# CSCAPrep Native Android

This is a native Kotlin and Jetpack Compose client for CSCAPrep.com. It does not
contain a WebView and does not embed the website.

Native features include guest Prep practice, account registration and login,
email-verification state, subject and difficulty selection, translated Prep,
timed Mock Exams, answer navigation, flags, submission, score results, history,
profile and study-language settings.

The app uses the secure mobile endpoints added in CSCAPrep Core 1.12.40 and the
existing CSCAPrep REST endpoints for learning content and exam operations.
